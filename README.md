## 🎯 Quick Start

### 1. Get Groq API Key (Free)
Visit [console.groq.com](https://console.groq.com) and create a free account

### 2. Deploy to Streamlit Cloud
1. Fork this repository
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your forked repo
4. Add your `GROQ_API_KEY` in Secrets
5. Deploy!

### 3. Start Researching
- Enter any company name (e.g., "Stripe", "Notion", "Figma")
- Get comprehensive competitive intelligence in 5-10 minutes
- Download results as JSON or TXT

## 🛠️ Tech Stack

- **LLM**: Groq (Llama 3.1 8B) - ⚡ 10x faster
- **Framework**: LangChain - Multi-agent orchestration
- **Scraping**: BeautifulSoup, Trafilatura - Web data extraction
- **UI**: Streamlit - Beautiful, interactive interface

## 📖 How It Works

The system uses 5 specialized AI agents:

1. **Web Research Agent** - Scrapes company website, extracts key information
2. **Social Media Agent** - Analyzes Twitter, Reddit, LinkedIn presence
3. **Financial Agent** - Gathers funding, revenue, and growth data
4. **Product Agent** - Analyzes features, pricing, and tech stack
5. **Synthesis Agent** - Combines all insights into strategic analysis
