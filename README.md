## 🎯 Quick Start

1. **Get Groq API Key** (free): https://console.groq.com

2. **Run the app**: https://your-app.streamlit.app

3. **Enter API key** in sidebar

4. **Research any company** - Try: Stripe, Notion, Figma

## 🛠️ Tech Stack

- **LLM**: Groq (Llama 3.1 70B)
- **Framework**: LangChain
- **Scraping**: BeautifulSoup, Trafilatura
- **UI**: Streamlit

## 📖 How It Works

1. **Web Research Agent** - Scrapes company website, extracts key info
2. **Social Media Agent** - Analyzes Twitter, Reddit, LinkedIn presence
3. **Financial Agent** - Gathers funding, revenue, growth data
4. **Product Agent** - Analyzes features, pricing, tech stack
5. **Synthesis Agent** - Combines all insights into strategic analysis
